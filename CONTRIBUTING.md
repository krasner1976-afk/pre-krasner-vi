# Contributing Guidelines

We welcome contributions, bug reports, and discussions regarding the **Pre-Krasner VI Framework** and its observational predictions for Galactic dynamics and Solar System celestial mechanics.

## How to Contribute

1. **Issues**: Open an issue to report bugs, suggest numerical improvements, or discuss theoretical questions.
2. **Pull Requests**:
   - Fork the repository.
   - Create a feature branch (`git checkout -b feature/new-analysis`).
   - Ensure all Python scripts run headlessly without errors and adhere to PEP 8.
   - Submit a pull request with a detailed description of your changes.

## Guidelines for Theoretical Extensions
- Clearly distinguish between exact mathematical derivations and phenomenological Ansätze.
- Include order-of-magnitude estimations or numerical scripts for any new physical predictions.
